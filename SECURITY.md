# Security Policy

If you believe you have found a security vulnerability in TcTidier, please do not open a public GitHub issue.

Use GitHub's private vulnerability reporting for this repository if it is enabled. If private reporting is not available, contact the maintainer directly through GitHub with:

- a short description of the issue
- affected versions or commit hashes
- reproduction steps or a proof of concept
- any suggested mitigation

We will acknowledge reports as quickly as practical, validate the issue, and coordinate a fix before public disclosure whenever possible.
