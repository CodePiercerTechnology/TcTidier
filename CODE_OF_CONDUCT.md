# Code of Conduct

TcTidier is a public project, and we want the repo to be useful, respectful, and low-drama for everyone who participates.

## Expected Behavior

- Be respectful and constructive in issues, pull requests, reviews, and discussions.
- Assume good intent, ask clarifying questions, and focus on improving the work.
- Share feedback about code and behavior without personal attacks.
- Be welcoming to contributors with different backgrounds and experience levels.

## Unacceptable Behavior

- Harassment, intimidation, or discriminatory language
- Personal insults or repeated bad-faith engagement
- Publishing private information without consent
- Deliberate disruption of community spaces or review threads

## Scope

This applies to repository issues, pull requests, reviews, release discussions, and other project communication channels.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer through GitHub so the issue can be reviewed and addressed.
